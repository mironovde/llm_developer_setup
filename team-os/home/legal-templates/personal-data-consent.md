## 4. Способы обработки персональных данных

Оператор осуществляет обработку персональных данных следующими способами:

- **Сбор** — получение данных от Пользователя через формы Сайта, электронную почту, мессенджеры.
- **Запись** — внесение данных в информационные системы и базы данных.
- **Систематизация** — организация данных по определённым критериям.
- **Накопление** — хранение данных на защищённых серверах.
- **Хранение** — обеспечение сохранности и неизменности данных.
- **Уточнение (обновление, изменение)** — актуализация данных по запросу Пользователя или при получении новой информации.
- **Извлечение** — получение данных из систем хранения для использования в указанных целях.
- **Использование** — применение данных для достижения указанных целей.
- **Передача (предоставление, доступ)** — передача данных третьим лицам в соответствии с разделом 5 настоящего Согласия.
- **Обезличивание** — приведение данных к виду, не позволяющему определить субъекта.
- **Блокирование** — временное прекращение обработки данных.
- **Удаление** — уничтожение данных без возможности восстановления.
- **Уничтожение** — окончательное удаление данных из всех систем.

Обработка осуществляется как с использованием средств автоматизации, так и без использования таких средств.

2. **Почтовым отправлением:** направив письменное заявление по адресу: {{LEGAL_ADDRESS}}.
3. **Через личный кабинет:** в разделе «Настройки» → «Персональные данные» (при наличии такой функциональности).

### 7.1. Требования к заявлению об отзыве

Заявление должно содержать:

- ФИО субъекта персональных данных
- Контактные данные (email, телефон), использованные при регистрации
- Перечень данных, согласие на обработку которых отзывается (или указание на отзыв в полном объёме)
- Дату и подпись (для письменного заявления)

### 7.2. Последствия отзыва

Оператор прекращает обработку персональных данных и уничтожает их в срок не более **30 (тридцати) дней** с момента получения заявления об отзыве, за исключением данных, обработка которых необходима для исполнения обязательств, предусмотренных законодательством РФ (п. 2 ч. 2 ст. 9 152-ФЗ).
