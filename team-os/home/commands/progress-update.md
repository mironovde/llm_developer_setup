# Progress Update — Обновление прогресса проекта

Обновление: $ARGUMENTS

## Auto mode (без аргументов)

Если `$ARGUMENTS` пустой — определи автоматически:
1. Определи текущий проект по working directory
2. Прочитай `git log --oneline -10` для последних изменений
3. Проверь TaskList для текущих задач
4. Обнови PROJECT_STATUS.md

## Trigger conditions

Этот skill вызывается когда:
- Фича завершена и смержена
- Ветка готова к merge
- Конец сессии с 3+ коммитами
- Явный запрос пользователя

## Формат PROJECT_STATUS.md

```markdown
# Project Status

**Проект**: [название]
**Обновлено**: [дата]
**Прогресс**: [X%]

## Текущие задачи
| # | Задача | Статус | Ветка |
|---|--------|--------|-------|
| 1 | [описание] | Done/In Progress/Blocked | feature/... |

## Завершённые фичи
- [дата] — [описание]

## Блокеры
- [описание] -> [решение]

## Следующие шаги
1. [задача]
```

## Memory integration

После обновления PROJECT_STATUS.md:
1. Добавь запись в History секцию project MEMORY.md
2. Обнови "Last verified" дату в MEMORY.md

Найди PROJECT_STATUS.md и обнови. Если нет — создай.
