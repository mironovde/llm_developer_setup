# Agent Team — Настройка команды агентов

TASK: Организовать команду агентов для [$ARGUMENTS] чтобы выполнить работу параллельно с атомарными результатами.

SUCCESS BRIEF:
- Тип выхода: работающий код / конфигурация от нескольких агентов
- Успех = все подзадачи выполнены, результаты интегрированы, тесты проходят

## Типы агентов

| Агент | Тип | Когда |
|-------|-----|-------|
| Explorer | `Explore` | Исследование кодовой базы |
| Researcher | `general-purpose` | Web search, документация |
| Implementer | `general-purpose` | Код, рефакторинг |
| Tester | `Bash` | Тесты, билды |
| Planner | `Plan` | Архитектура |

## Процесс

1. Декомпозиция (`/task-decompose` если не сделана)
2. Распределение: тип агента + промпт + ожидаемый результат
3. Запуск итерациями: волна 1 (параллельные) → волна 2 (зависимые) → ...
4. Координация: проверка совместимости → интеграция → тесты

## Правила

1. Полный контекст в промпте каждого агента
2. Чёткие границы (разные файлы)
3. Явные зависимости
4. `run_in_background: true` для длительных задач
5. Проверка результатов после каждой волны
6. Количество агентов = рационально: больше для мелких независимых, меньше для связанных
7. Между волнами НЕ спрашивать пользователя — делать подряд

## Формат плана

```
AGENT TEAM PLAN
===============
Задача: [описание]
Агентов: [N] в [M] волнах

Волна 1 (параллельно):
  Agent 1 [тип]: [задача] → [ожидаемый результат]
  Agent 2 [тип]: [задача] → [ожидаемый результат]

Волна 2 (после волны 1):
  Agent 3 [тип]: [задача] → [ожидаемый результат]

Интеграция: [план]
```

Составь план и запусти агентов.
