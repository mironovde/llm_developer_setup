# DECISIONS — ADR journal

> Append-only. The user may veto any decision retroactively: set status to `vetoed`, add a journal line, replan.

Entry template:

## ADR-000: <title>
- date: YYYY-MM-DD · status: proposed | accepted | superseded | vetoed · tier: T2
- context: <1–3 lines: why a decision was needed>
- options: A) <…> B) <…> C) <…>
- choice: <letter> — <reason in one line>
- consequences: <what this constrains or enables>
