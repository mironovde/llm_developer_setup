# PLAYBOOK — пошаговые сценарии

> Все сценарии предполагают установленный Team OS (`install.sh`) и проект из `project-template/`.

## 1. Новый продукт с нуля (T3)

1. `cp -R team-os/project-template/. ~/projects/app && cd ~/projects/app && git init && claude`
2. Первая сессия: Init protocol (стек, команды) → опиши идею продукта.
3. Лид объявит `[T3]` и поведёт полный цикл: discovery (`pm`+`researcher`+`ux`) → PRD в `team/specs/` → архитектура + ADR → roadmap в BACKLOG → спринты.
4. Твои ворота (L2 по умолчанию): подтверждение PRD и дизайн-дайджеста; дальше команда едет сама до конца спринта.
5. Конец спринта: adversarial-ревью (два независимых ревьюера) → релиз через твои ворота → авто-ретро с уроком в `solutions/`.

## 2. Развитие существующего продукта

1. Скопируй в репозиторий `project-template/team/` + `.claude/` + `.mcp.json` (или дай лиду команду «инициализируй Team OS в этом репо» — он перенесёт шаблон сам).
2. Первая сессия заполнит PRODUCT.md по коду (стек, команды — из lockfile'ов).
3. Ставь задачи; фичи пойдут по T2-конвейеру, мелочь — T0/T1.

## 3. Большой рефакторинг (T3)

Скажи «большой рефакторинг X». Лид: карта миграции от `architect` (что движется, обратимость каждого шага) → ADR → спринты со шажками «зелёные тесты после каждого» → adversarial-ревью. Незнакомая подсистема → сперва `researcher`.

## 4. Быстрая задача (T0/T1)

Просто напиши: «поправь опечатку в …». Увидишь `[T0] plan: …` и результат одним проходом с самопроверкой — без команды и церемоний. Не согласен с тиром → `/tier T1 <задача>`.

## 5. Ночной автопилот (L3)

```bash
cd ~/projects/app
# бэклог должен быть в SPRINT.md/Tasks; проверь ворота:
~/.claude/teamos/bin/doctor .
caffeinate -i ~/.claude/teamos/bin/autopilot . --max-iterations 15
```

- Итерация = свежий контекст: «одна единица работы из состояния на диске».
- Лимит окна Max: скрипт читает точный `resetsAt` из события лимита, спит и продолжает.
- Утром: `~/.claude/teamos/bin/standup .` + `team/.autopilot/log`. Если есть `team/HALT` — команда упёрлась в решение, которое может принять только человек; ответь в чате обычной сессией и перезапусти.
- Деплой/merge/force-push ночью железно запрещены (hook): всё такое копится в SPRINT под «awaiting user gate».

## 6. Вмешательство пользователя

| Хочу | Делаю |
|---|---|
| Изменить продуктовое направление | Пишу в чат решение — лид журналирует и перепланирует без драмы |
| Отменить решение команды | «veto ADR-7» → статус vetoed, перепланирование |
| Больше/меньше контроля | `/autonomy L1` (спрашивать о продуктовых) … `/autonomy L3` |
| Принудительный процесс | `/tier T2 <задача>` |
| Статус почти бесплатно | `/standup` (или из терминала `teamos/bin/standup .`) |
| Экономика недели | `~/.claude/teamos/bin/efficiency-report . --days 7` |

## 7. Ежемесячный ресёрч экосистемы

`/research-refresh` — исследователь сканирует changelog/маркетплейсы/пиненые MCP и отдаёт diff-рекомендации («появилось X, заменяет наш Y, эффект Z, риск W»). Принятие — только через Gym (см. §8). Автозапуск по расписанию: `claude -p "/research-refresh" --permission-mode acceptEdits` в cron/launchd раз в месяц, либо scheduled task в приложении Claude.

## 8. Изменение конфигурации (железное правило)

1. Ветка в репо настроек → правка `team-os/home/...`.
2. `bash team-os/gym/run.sh all` → сравнить с `gym/results/baseline.json`: pass-rate И токены не хуже.
3. Хуже → откат правки. Не хуже → merge, `install.sh`, и `run.sh all --baseline` для нового базлайна.
4. Урок/причина — ADR в docs/DECISIONS.md.

## 9. Восстановление

| Ситуация | Действие |
|---|---|
| Вернуть старый конфиг | `cp -R ~/.claude/teamos-backups/<ts>/. ~/.claude/` |
| Сессия оборвалась посреди работы | Новая сессия в проекте: лид сам поднимет контекст из SPRINT + JOURNAL |
| Loop-guard блокирует стоп, а цикл давно мёртв | Он сам fail-open после 5 блокировок; вручную: `rm team/artifacts/.browser-loop.json` |
| Подозрение на кривой конфиг | `claude --safe-mode` (всё кастомное выключено) + `teamos/bin/doctor` |
| Gym-задача падает из-за отсутствия Xcode/Chrome | Это SKIP, не провал: `doctor` покажет, чего не хватает на этой машине |
