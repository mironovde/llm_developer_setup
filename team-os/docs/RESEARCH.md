| Факт | Статус vs Приложение А | Следствие для дизайна |
|---|---|---|
| `--max-turns` в CLI **отсутствует** (есть только в Agent SDK) | CONFIRMED (подозрение А подтверждено) | Лимит итераций автопилота — собственным wrapper'ом (`scripts/autopilot`) |
| `--max-budget-usd` (только с `-p`) существует | НОВОЕ | Пояс безопасности; но на подписке бюджеты считаем по usage из stream-json, не по USD |
| `--json-schema` (print) — валидируемый структурный вывод | НОВОЕ | Судья Gym возвращает `grading.json` строго по схеме — без парсинга прозы |
| `--permission-mode`: `acceptEdits\|auto\|bypassPermissions\|manual\|dontAsk\|plan` | CHANGED (появились `auto`, `dontAsk`, `manual`) | Автопилот: `acceptEdits` + точечные allowlists; `bypassPermissions` не используем (§8) |
| `--setting-sources user,project,local` + `--settings <file>` + `--strict-mcp-config` | CONFIRMED | **Ключевое решение**: Gym-прогоны герметичны (`--setting-sources project`) — глобальный конфиг пользователя не грузится: чисто и дёшево |
| `--bare` — минимальный режим, auth **только** `ANTHROPIC_API_KEY` | НОВОЕ | На подписке Max неприменим; для лёгких прогонов используем `--setting-sources` + `--disable-slash-commands` |
| `--effort low..max`, `--fallback-model`, `--fork-session`, `--session-id`, `--no-session-persistence` | НОВОЕ/CONFIRMED | `--effort low` для судьи Gym; `--fallback-model` для устойчивости ночных прогонов |
| Алиасы моделей в help: `fable`, `opus`, `sonnet` (+ полные ID) | CHANGED (появился ярус Fable/Mythos над Opus) | Ярусы моделей задаём алиасами; актуальный список — см. §3 ниже (после скана доков) |
| `--include-hook-events` (stream-json) | НОВОЕ | Отладка hook-контура Gym без интерактива |
